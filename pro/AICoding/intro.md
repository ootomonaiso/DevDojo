# あなたの先生は今日からAIです
AIを詰問することで人生を豊かに

## 生成AIをコーディングに使うための必要な知識・スキル

### 1. 基本的なプログラミング知識
なくったってAIを尋問してあなたがその知識を得れば問題はないです
- **言語の基礎文法**: 変数、関数、クラス、制御構文などの基本概念
- **エラーの読み方**: エラーメッセージを理解して原因を特定できる
- **デバッグの基本**: ログ出力、ブレークポイント、ステップ実行などの手法
- **コードの読解力**: 他人（AI含む）が書いたコードを理解できる

### 2. プロンプトエンジニアリングスキル
なくったってあなたに国語力があれば問題はないです
- **具体的な指示**: 曖昧な表現を避け、明確で詳細な要求を書く
- **コンテキストの提供**: 現在のコード、エラーメッセージ、環境情報を含める
- **段階的な質問**: 複雑な問題を小さな部分に分解して質問する
- **例示の活用**: 期待する出力例やコードの形式を示す

### 3. コード品質の判断基準
なくったってあなたがコード設計についてAIに詰問すれば問題はないです
- **可読性**: コードが理解しやすいかどうか
- **保守性**: 後から修正や拡張がしやすいか
- **パフォーマンス**: 実行速度やメモリ使用量は適切か
- **セキュリティ**: 脆弱性やセキュリティホールがないか
- **テスト可能性**: ユニットテストが書きやすい構造になっているか

### 4. 開発環境とツールの理解
なくったってあなたがスクショ送りながら一緒に作業をすれば問題はないです
- **IDE/エディタ**: VS Code、IntelliJ、Vimなどの基本操作
- **バージョン管理**: Git の基本的な使い方（add, commit, push, pull）
- **パッケージ管理**: npm、pip、Maven などの依存関係管理
- **ビルドツール**: webpack、Maven、Gradleなどの基本理解
- **デバッグツール**: ブラウザの開発者ツール、IDE のデバッガー

### 5. AI生成コードの検証方法
なくったってどうせあなたが動かしてデバッグするんだから問題はないです
- **動作テスト**: 実際に実行して期待通りに動作するか確認
- **エッジケースの考慮**: 境界値や異常系での動作確認
- **コードレビュー**: 生成されたコードの論理的な妥当性をチェック
- **セキュリティチェック**: 入力値検証、SQLインジェクション対策など
- **パフォーマンス測定**: 実行時間やメモリ使用量の測定

## まとめ
生成AIをあなたの知識を得るための足掛かりにしてください。生成AIをいいように扱える人になってください。
