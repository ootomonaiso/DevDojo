# プログラミング能力とはいったい何なのか?
- プログラミング能力は単にコーディングができるだけのものではない
  - 問題の切り分け、分析ができる力
  - 順序だてて考えられる力

**「コードを書くこと」はコーディングであり、コーディングはプログラミングの1つの手順である**

---
# 問題の切り分けとは
図書館で使う蔵書の管理システムを作りたい
↓
必要機能切り分け
  - 蔵書の登録
  - 蔵書の検索
  - 蔵書の貸出
  - 蔵書の返却
---
# 切り分けの着眼点
- 扱う「もの」を基準に分ける
  - 蔵書と利用者のデータは別のもの
- それぞれの「もの」に対して、どのような「操作」が必要かを考える
  - 蔵書には登録、検索、貸出、返却の操作が必要
  - 利用者には登録、検索、貸出履歴の確認が必要

もの＝オブジェクトと操作＝メソッドで考える
