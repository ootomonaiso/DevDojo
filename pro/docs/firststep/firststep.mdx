# プログラミング基礎
## 第1回：プログラミングをするうえで要求される知識

---
# プログラミング能力とは？
- コードを書くこと＝コーディングは一部
- 問題の分解・設計・検証・伝達まで含む
- 順序立てて考える力

---
# プログラミングの構成要素
- コーディング（言語ごとの書き方）
- アルゴリズム・構造の設計
- デバッグ（どこが悪いか当たりをつける）

---
# プログラマーに必要なスキル
- 論理的思考力
- 読解力・要約力
- 調査力（ググる力）
- 作法を守る力

---
# 別の視点を持つ
- 技術者としての目・利用者としての目
- 新しい技術を知る
- サービス思考：自分のものが他人に受け入れられる工夫

---
# 目的・本質を考える
- 何をどう作るか、その目的を常に意識
- ソフトウェア＝ツール本体＋作法
- 誰かに伝わるように作る・説明できるようにする

---
# わからないことは放置しない
- 論理的に分からないことは早めに解決
- 自分なりの「解釈」ができるまで粘る
- 言語化・ドキュメント化を習慣に

---
# 記録・ドキュメントの重要性
- ドキュメントでまとめる
- 言葉どうしの関連性を意識
- 自分の言葉で説明する
- 一度学んだことも繰り返し整理

---
# 言語の作法を守る
- 作法・キモを知る（TypeScript, Java, C, C++ など）
- 自分なりのコーディングルールを作って守る
- 言語の特性を知り、バグを防ぐ・レビューしやすく

---
# DevDojoの方針
- 知識から入って根本的な部分から理解
- プログラムに対する理解度の向上
- 応用的な知識も身につける
- 長持ちするシステムを目指す
